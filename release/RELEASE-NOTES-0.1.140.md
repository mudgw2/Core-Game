# CORE 0.1.140 — System-Driven Planetary Sky

This release introduces the first system-aware astronomical presentation layer
for the planetary test world.

## Included
- The planetary world receives the full generated system record.
- The renderer supports one or more stars, optional central non-stellar bodies,
  and explicit celestial-body collections.
- Existing binary systems display a deterministic companion even though older
  saved system records only store a primary star and an `is_binary` flag.
- Planet rotation timing uses a world-provided rotation period when available;
  otherwise it is derived deterministically from the world seed.
- Lighting is evaluated against the player's local surface normal, so day/night
  conditions vary with planetary location.
- A deterministic background starfield fades in at night.

## Compatibility
- No universe generation algorithm, generator version, seed fingerprint, or
  persistent player data is changed.
- Existing saved universe records remain readable.
- The current universe generator still stores only a primary star plus a binary
  flag. Full multi-star and non-stellar central-body data are supported by the
  renderer when present, but are not yet generated by the current generator.
