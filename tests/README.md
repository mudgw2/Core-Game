# CORE automated QA (0.1.9)

Routine QA is available from the browser Workbench using **Run automated tests**. The optional CLI runner checks PHP syntax and core behaviors: `php tests/run.php`. All persistence tests use temporary directories.


The 0.1.49 suite also verifies module registration, dependency resolution, cycle and duplicate detection, shared service injection, and the demonstration module. The browser QA suite reports its release version from `api/qa.php`.


Release 0.1.52 adds the public player website, initial account registration/sign-in, a gated player portal, system detail fields, and route-based travel controls. The 0.1.51 Babylon.js sizing and diagnostic improvements remain.
